# enslaved-vr-mod

A work-in-progress VR mod for **Enslaved: Odyssey to the West — Premium
Edition** (Ninja Theory, 2010; PC port 2013, BANDAI NAMCO), a game built on
Unreal Engine 3 with Ninja Theory's custom engine layer and no existing VR
conversion.

> ## ⚠️ This is NOT playable in VR yet
>
> **Do not install this expecting to play Enslaved in a headset — it will not
> do that right now.** There is currently no VR output, no stereo rendering,
> no head tracking, and nothing shows up in a headset. This repository is the
> future home of the released mod, published early so the project is visible
> and backed up — not a released VR mod.
>
> **This notice will be changed only when the mod genuinely renders the game
> in a headset.**

## Scope, ethics, and legality

- Non-commercial fan project. Requires owning a legitimate copy of the game.
- **No original game assets are redistributed** — only files we create.
- We credit everyone whose work this builds on and honour correction and
  removal requests from rights holders. See the research repo's `CREDITS.md`.

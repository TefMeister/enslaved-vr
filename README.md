# enslaved-vr-dev-archive

The messy, in-progress development history of the **Enslaved: Odyssey to the
West VR mod**: snapshots, probes, experiments, and dead ends, preserved as they
happened. For the readable version of events, see
[`enslaved-vr-modding-notes`](https://github.com/TefMeister/enslaved-vr-modding-notes);
for distilled engine knowledge, see
[`enslaved-vr-engine-research`](https://github.com/TefMeister/enslaved-vr-engine-research).

No original game files are stored here — only files we create. Non-commercial
fan project; requires owning a legitimate copy of the game.

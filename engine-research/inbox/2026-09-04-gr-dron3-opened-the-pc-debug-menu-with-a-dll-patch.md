# dron_3 opened this game's PC debug menu with a `dinput8.dll` patch (2020), and the PS3 debug camera with one `li r3,0` — the in-process route is a gate to defeat, not a dispatcher to find

Filed by: `/gr`, 2026-09-04
Topic: `external-research/topics/2026-09-04-the-debug-menu-ships-in-the-pc-build-and-a-dll-patch-opens-it.md`
Dossier sections: §7 ("What remains for a command channel"), §8/§9 (in-process free camera); the board's two `[PD]` in-process rows

- **The debug menu ships in the PC build.** dron_3, 2020-11-02: drop a `dinput8.dll` into `Binaries\Win32\`, then *"BACKSPACE + ESCAPE on keyboard, BACK + START or SELECT + START on gamepad"* during play. `[reported 2026-09-04]` On PS3 (2017, v1.01) a **single instruction** `0150BB34 38600000` (`li r3,0`) enables *"Debug Menu (SELECT+START) and Debug Camera (L3+R3)"* — one function forced to return zero, the shape of a defeated "debug allowed" predicate. Nothing downloaded or examined; only the fact that it works.
- **⇒ Row 2 and row 3 change shape.** Not "locate the engine's exec entry point by pattern" — the entry point is a chain of eight `ScriptConsoleExec` calls, not a function — but **either** (A) find and defeat the gate (candidates: `GameInfo.AllowCheats` or Ninja Theory's override, which decides whether `AddCheats()` builds the `GameCheatManager` that owns `ToggleDebugCamera`; or the game-specific check behind `CheckDebugCamChord`/`DoDebugCamChord`, whose exec-name strings are in the exe) **or** (B) call the script functions directly.
- **(B) is the SDK-generator recipe, public and MIT:** pattern-find `GObjects`/`GNames`, walk to the live `PlayerController` and the `UFunction`s by name, call via `UObject::ProcessEvent` (vtable index or pattern). ItsBranK's UE3SDKGenerator and the CodeRed Generator both document it for 32-bit UE3. The sequence: `ProcessEvent(PC, AddCheats, {bForce=true})` (plain script function, not FINAL_RELEASE-guarded) → `ProcessEvent(PC.CheatManager, ToggleDebugCamera, …)`; and `ProcessEvent(PC, ConsoleCommand, {"…"})` restores the whole command vocabulary through the engine's own chain. `[inferred-static]` — the one unknown is whether `CheatClass` still names a real class in this build; if not, (A).
- **vorpX ships a geometry-3D profile** for this game (RJK_, 2019, "Full VR with Headtracking") — independent corroboration that the projection is interceptable per draw; nothing about where. `[reported]`
